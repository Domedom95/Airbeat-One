# Airbeat One v5 – persönliche Packliste + gemeinsame Daten

## Verhalten
- Packliste: nur lokal auf dem jeweiligen Handy/Browser.
- Timetable: gemeinsam für alle Geräte über Supabase.
- Crew-Treffpunkt und Crew-Notizen: gemeinsam für alle Geräte über Supabase.

## Einmalige Einrichtung
1. Kostenloses Supabase-Projekt erstellen.
2. SQL Editor öffnen und `supabase-setup.sql` ausführen.
3. In Supabase unter Project Settings / API:
   - Project URL kopieren
   - anon/public key kopieren
4. Beide Werte in `config.js` eintragen.
5. `config.js` wieder bei GitHub hochladen.

Danach sehen alle Freunde denselben Timetable und dieselben Crew-Infos.
